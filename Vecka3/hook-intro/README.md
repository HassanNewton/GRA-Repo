# React Del 3 - Kodexempel

Här finns kodexempel från genomgången av State, Lifetime Hooks och Forms.

## Filer efter tema

### State (useState)
- **01-state-basic.jsx** - Enkel räknare med state
- **02-state-datatypes.jsx** - State med sträng, boolean och objekt
- **10-state-class.jsx** - State i klasskomponent

### useEffect (Lifetime Hooks)
- **03-useeffect-mount.jsx** - Hämta data när komponenten laddar
- **04-useeffect-dependency.jsx** - Köra kod när specifika variabler ändras
- **05-useeffect-search.jsx** - Söka/filtrera när inputen ändras

### Forms (Formulär)
- **06-form-simple.jsx** - En input med submit
- **07-form-multi.jsx** - Flera inputs med onChange
- **08-form-object.jsx** - Använd objekt för form-state (bättre pattern)
- **12-form-validation.jsx** - Validering och felmeddelanden

### Klasskomponent
- **11-class-lifecycle.jsx** - componentDidMount för data-hämtning

### Bonusexempel (Kombinerar flera koncept)
- **09-todo-app.jsx** - State + useEffect + forms (kompletus app)
- **13-product-list.jsx** - Lista med add/delete/filter
- **14-toggle-tabs.jsx** - Toggle och tab-system
